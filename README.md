## 🕹️ Cómo jugar a Esquivar Tuberías

- **Espacio** o **clic** → Saltar
- **P** o **ESC** → Pausar
- **Móvil**: Botones ▲ (saltar) ⏸ (pausa) en pantalla

Atraviesa tuberías, colecciona monedas 🪙 y jamones 🍖 para recuperar vida.
